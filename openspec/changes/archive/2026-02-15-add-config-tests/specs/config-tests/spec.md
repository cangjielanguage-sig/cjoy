## Overview

补充 CJoy 框架 config 模块的测试用例，提高代码质量和稳定性。

## Requirements

### 1. ArgConfigLoader 测试

#### 1.1 基本功能测试
- 测试值包含等号的配置项
- 测试无效参数格式（如缺少值的 -D 参数）
- 测试优先级参数设置

#### 1.2 边界条件测试
- 测试空参数数组
- 测试大量参数
- 测试超长参数名和值

### 2. JsonConfigLoader 测试

#### 2.1 基本功能测试
- 测试文件不存在的异常处理
- 测试无效 JSON 文件的异常处理
- 测试空文件的处理
- 测试 JSON 中包含复杂嵌套结构
- 测试优先级参数设置

#### 2.2 边界条件测试
- 测试超大 JSON 文件
- 测试包含特殊字符的配置值

### 3. PropertiesConfigLoader 测试

#### 3.1 基本功能测试
- 测试文件不存在的异常处理
- 测试无效 properties 文件的异常处理
- 测试空文件的处理
- 测试值包含等号的配置项
- 测试注释行处理
- 测试优先级参数设置

#### 3.2 边界条件测试
- 测试超大 properties 文件
- 测试包含特殊字符的配置值

### 4. ConfigManager 测试

#### 4.1 基本功能测试
- 测试环境变量配置的加载和访问
- 测试配置合并的优先级（环境变量 > 命令行 > JSON > properties）
- 测试配置未找到时的默认值返回
- 测试 bind 方法支持更多类型（如布尔值、浮点数、自定义类）
- 测试 resolve 方法的复杂表达式（如嵌套引用、多个引用）

#### 4.2 边界条件测试
- 测试大量配置项的加载
- 测试循环引用的配置表达式
- 测试超长配置路径
